Reference for `config.yaml`.

Environment placeholders like `${VAR_NAME}` resolve at runtime.

## Top-level Keys

- `sources`: connector list for ingestion jobs
- `embedding`: embedding provider + model config
- `inference`: LLM provider + model config for rephrase/chat tasks
- `vector_store`: chunking and pgvector/HNSW settings

## `sources`

The supplied configuration enables one Directory source by default:

```yaml
sources:
  - type: "directory"
    name: "local_docs"
    enabled: true
    config:
      path: "${DIRECTORY1_PATH}"
      recursive: true
      exclude_hidden: true
      exclude_empty: false
      schedules: "${DIRECTORY1_SCHEDULES}"
```

With the example environment and Compose file, the host directory
`./data/input` is mounted at `/data/input`. S3 and the other remote connectors
are optional commented examples.

Each item:

```yaml
- type: "directory" # or s3 / mediawiki / serpapi / etc.
  name: "local_docs"
  config:
    # connector-specific fields
```

Connector `config` fields differ by connector type. See connector pages for exact keys.

### Common Connector Fields

The following fields are supported by all connector types:

| Field | Required | Default | Description |
|---|---|---|---|
| `schedules` | no | `3600` | Ingestion interval in seconds |
| `request_delay` | no | `0` | Seconds to wait between outbound API requests. Increase to avoid rate-limiting (e.g. `0.1`) |

## `embedding`

```yaml
embedding:
  provider: local # local | ollama | openrouter | openai
  model_config: sentence-transformers/all-mpnet-base-v2
  embedding_dim: 768
```

- `provider`: embedding backend; `local` is the default and needs no API service
- `model_config`: model id/name used by provider
- `embedding_dim`: vector dimension returned by model

> WARNING: once embedding dimension is set, it cannot be changed without rebuilding the index.

## `inference`

```yaml
inference:
  provider: ollama # ollama | openrouter | openai
  model_config: "${OLLAMA_DEFAULT_MODEL}"
```

- `provider`: inference backend; `ollama` is the default
- `model_config`: chat/rephrase model ID (`qwen2.5:14b` in the example environment)

For Ollama, set the shared root URL to
`OLLAMA_BASE_URL=http://100.85.191.78:11434` in `.env`. Do not add `/v1`:
Compose supplies the root URL to both OpenWebUI and the backend, and ROAT appends
`/v1` internally for its OpenAI-compatible client. The selected model must already
exist on the external Ollama server.

To opt into OpenRouter or another OpenAI-compatible endpoint, change `provider`
to `openrouter` or `openai` and configure `OPENROUTER_API_BASE` and
`OPENROUTER_API_KEY` in `.env.rag`.

> NOTE: inference backend is not used for vector search, only for the rephrase endpoint.

## `vector_store`

```yaml
vector_store:
  table_name: embeddings
  hybrid_search: true
  chunk_size: 512
  chunk_overlap: 50
  hnsw:
    hnsw_m: 16
    hnsw_ef_construction: 64
    hnsw_ef_search: 40
    hnsw_dist_method: vector_cosine_ops
```

- `table_name`: embeddings table name
- `hybrid_search`: vector + keyword retrieval toggle
- `chunk_size`: chunk size for indexing
- `chunk_overlap`: overlap between adjacent chunks
- `hnsw.hnsw_m`: graph neighbors per node
- `hnsw.hnsw_ef_construction`: index build quality/speed tradeoff
- `hnsw.hnsw_ef_search`: search recall/speed tradeoff
- `hnsw.hnsw_dist_method`: vector distance operator
