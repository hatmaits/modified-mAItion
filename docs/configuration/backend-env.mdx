Reference value for `.env.rag` file.

## Application Setup

- `REDIS_URL`: Redis connection URL
- `POSTGRES_USER`: Postgres username
- `POSTGRES_PASSWORD`: Postgres password
- `POSTGRES_DB`: backend database name
- `POSTGRES_HOST`: Postgres host/service name
- `POSTGRES_PORT`: Postgres port
- `DATABASE_URL`: complete backend database connection URL

## Ollama Provider (Default)

- `OLLAMA_API_KEY`: client compatibility placeholder (default: `ollama`; ignored by Ollama when authentication is not configured)
- `OLLAMA_BASE_URL`: shared external Ollama root URL injected by Compose from the root `.env` file (default: `http://100.85.191.78:11434`)
- `OLLAMA_DEFAULT_MODEL`: backend rephrase model injected by Compose from the root `.env` file (default: `qwen2.5:14b`)

Set `OLLAMA_BASE_URL` once in the root `.env` and keep it free of a `/v1` suffix.
Compose injects the same root URL into the backend and OpenWebUI; ROAT appends
`/v1` internally for its OpenAI-compatible client. Set `OLLAMA_DEFAULT_MODEL` in
that same file. The selected model must already exist on the external server.

## OpenAI-Compatible Provider (Optional)

- `OPENROUTER_API_KEY`: API key for OpenRouter or another OpenAI-compatible backend
- `OPENROUTER_API_BASE`: compatible provider base URL (default example: `https://openrouter.ai/api/v1`)

These variables are ignored while `inference.provider` is `ollama` in
`config.yaml`. To opt in, change that provider to `openrouter` or `openai`.

## Default Directory Connector

- `DIRECTORY1_PATH`: path inside the worker container (default: `/data/input`)
- `DIRECTORY1_SCHEDULES`: ingestion interval in seconds (default: `3600`)

The corresponding host path is `DIRECTORY_HOST_PATH` in `.env` and defaults to
`./data/input`.

## Workers and Limits

- `CELERY_CONCURRENCY`: number of Celery worker processes
- `MAX_TASK_CHILD`: max tasks per child process before recycle
- `MAX_MEMORY_PER_CHILD`: per-child memory cap (KB)

## ONNX Runtime / GPU

- `CUDA_VISIBLE_DEVICES`: visible GPU device list
- `ORT_DISABLE_GPU`: disable GPU for ONNX Runtime (`1`/`0`)
- `ORT_DYLD_DISABLE_GPU`: disable GPU for ONNX Runtime on DYLD-based systems

## CORS

- `CORS_ORIGINS`: allowed origins list for cross-origin requests

> NOTE: the value can be provided in a Python-syntax string, e.g. `["http://localhost","http://localhost:3000"]`

## Rate Limiting

- `ENABLE_RATE_LIMIT`: enable rate limiting (`True`/`False`)
- `CHUNK_RATE_LIMIT`: rate limit for chunk endpoint (example: `30/minute`)
- `REPHRASE_RATE_LIMIT`: rate limit for rephrase endpoint (example: `30/minute`)

## MCP Server

- `MCP_ENABLE`: enable the MCP server (`1`/`0`, default: `0`)
- `MCP_API_KEY`: Bearer token clients must present to authenticate. Required when `MCP_ENABLE=1` — the service will not start if this is empty. Generate with `openssl rand -hex 32`

## Minimal Default Provider and Source Example

```dotenv
OLLAMA_API_KEY=ollama
# OLLAMA_BASE_URL=http://100.85.191.78:11434 is supplied from the root .env
# OLLAMA_DEFAULT_MODEL=qwen2.5:14b is supplied from the root .env

OPENROUTER_API_KEY=
OPENROUTER_API_BASE=https://openrouter.ai/api/v1

DIRECTORY1_PATH=/data/input
DIRECTORY1_SCHEDULES=3600
```
