Reference for `.env`, created from `.env.openwebui.example`. In addition to
OpenWebUI settings, this file supplies host-side Docker Compose values.

## URL and Port

- `WEBUI_URL`: public URL of OpenWebUI (example: `http://localhost:3000`)
- `WEBUI_BIND_HOST`: host interface used by the published port (default: `127.0.0.1`)
- `HTTP_WEB_PORT`: host port mapped to OpenWebUI container
- `WEBUI_SECRET_KEY`: app secret key (generate strong random value)
- `DIRECTORY_HOST_PATH`: host directory mounted read-only into the ingestion worker (default: `./data/input`)

## Database

- `POSTGRES_USER`: Postgres username
- `POSTGRES_PASSWORD`: Postgres password
- `POSTGRES_DB`: Postgres database name
- `POSTGRES_HOST`: Postgres host/service name
- `POSTGRES_PORT`: Postgres port

## Admin Provisioning

- `X_WEBUI_ADMIN_USER`: initial admin display name
- `X_WEBUI_ADMIN_EMAIL`: initial admin email
- `X_WEBUI_ADMIN_PASS`: initial admin password
- `WEBUI_AUTH`: enable web authentication (`True`/`False`)
- `ENABLE_SIGNUP`: allow signup on first boot (`True`/`False`)
- `ENABLE_LOGIN_FORM`: enable login form (`True`/`False`)

> Note: keep `ENABLE_SIGNUP=True` on first start so admin account auto-provisioning
works. After first boot, you can disable it to run in single-user or private modes.

## Ollama Provider (Default)

- `ENABLE_OLLAMA_API`: configure OpenWebUI's native Ollama provider (default: `True`)
- `OLLAMA_BASE_URL`: shared external Ollama root URL (default: `http://100.85.191.78:11434`)
- `OLLAMA_DEFAULT_MODEL`: installed model selected in OpenWebUI and ROAT (default: `qwen2.5:14b`)

Do not append `/v1` to `OLLAMA_BASE_URL`. OpenWebUI uses Ollama's native API,
while Compose passes the same root URL to ROAT and ROAT appends `/v1` internally.
The Compose stack does not install models; `qwen2.5:14b` must already exist on the
external server.

## OpenAI-Compatible Provider (Optional)

- `ENABLE_OPENAI_API`: auto-provision provider settings (`True`/`False`)
- `OPENAI_API_BASE_URL`: provider base URL (example: `https://openrouter.ai/api/v1`)
- `OPENAI_API_KEY`: provider API key
- `OPENAI_DEFAULT_MODEL`: default model ID

These settings are disabled in the example. Set `ENABLE_OLLAMA_API=False` and
`ENABLE_OPENAI_API=True` to use an OpenAI-compatible provider as the default.
If both are enabled, Ollama takes priority as the default model.

## Runtime

- `ENV`: runtime mode (example: `dev`)
- `UVICORN_WORKERS`: number of Uvicorn workers
- `USER_AGENT`: outgoing user agent string

## Minimal Example

```dotenv
WEBUI_URL=http://localhost:3000
WEBUI_BIND_HOST=127.0.0.1
HTTP_WEB_PORT=3000
DIRECTORY_HOST_PATH=./data/input
WEBUI_SECRET_KEY=<random-hex>

POSTGRES_USER=postgres
POSTGRES_PASSWORD=postgres
POSTGRES_DB=openwebui
POSTGRES_HOST=postgres
POSTGRES_PORT=5432

X_WEBUI_ADMIN_USER=Admin
X_WEBUI_ADMIN_EMAIL=admin@example123.com
X_WEBUI_ADMIN_PASS=<strong-password>
WEBUI_AUTH=True
ENABLE_SIGNUP=True
ENABLE_LOGIN_FORM=True

ENABLE_OLLAMA_API=True
OLLAMA_BASE_URL=http://100.85.191.78:11434
OLLAMA_DEFAULT_MODEL=qwen2.5:14b

ENABLE_OPENAI_API=False
OPENAI_API_BASE_URL=https://openrouter.ai/api/v1
OPENAI_API_KEY=
OPENAI_DEFAULT_MODEL=openai/gpt-4.1-nano

ENV=dev
UVICORN_WORKERS=1
USER_AGENT=rag-of-all-trades+openwebui/0.6.5
```
